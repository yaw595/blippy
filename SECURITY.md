# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use GitHub's private reporting
instead: go to the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the Blippy and macOS versions. You will get a
reply as soon as the maintainers can; please allow some time, this is a volunteer project.

## Scope

Anything that lets another device or app read, change or delete your files without your
approval, break the encryption between your devices, or run code on your Mac through Blippy.

## Supported versions

Only the latest release is supported.
